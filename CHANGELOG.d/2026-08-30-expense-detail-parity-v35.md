# Expense detail parity v35

- Overview Expenses now opens a dedicated monthly Expense Detail screen instead of the generic Transactions view.
- Expense Detail uses the same compact visual hierarchy as Income Detail: title and amount aligned, metadata grouped underneath, compact status pills, then a consistent action row.
- Expense records continue to show category, date, payer, paying account, fixed/variable type, paid/unpaid status, Edit/Delete and payment-status controls.
- Recorded expense total reconciles to the Overview expense total.
- No expense calculations or stored financial evidence were changed.
