# Savings detail parity

- Makes the Overview Savings Snapshot card open the Savings view directly.
- Rebuilds monthly savings accounts into the same compact ledger geometry used by Income and Expense detail rows.
- Displays account balances as formatted currency in a stable top-right position.
- Replaces always-visible large form fields with explicit Edit / Save / Cancel controls while preserving Delete and + Account.
- Keeps month-scoped savings storage and calculations unchanged.
- Adds a regression test for Savings navigation, currency presentation, edit controls and mobile visual parity.
